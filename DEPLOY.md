# Deploy for free: Render + Aiven MySQL + Cloudinary

Render runs the API and admin panel. Render has **no MySQL**, and its free disk is
**wiped on every restart**, so two other free services hold the data:

| What | Where | Free plan |
|---|---|---|
| API + admin website | Render (web service) | sleeps after 15 min idle, ~50 s to wake |
| MySQL database | Aiven | 1 CPU, 1 GB storage |
| Item photos | Cloudinary | 25 monthly credits (plenty to start) |

You need accounts on GitHub, Render, Aiven and Cloudinary.

---

## 1. Database: Aiven MySQL

1. https://console.aiven.io → **Create service** → **MySQL** → plan **Free** → pick a region near Singapore.
2. When it's running, open the service's **Overview** → *Connection information*. You need:
   **Host**, **Port**, **User** (`avnadmin`), **Password**, **Database** (`defaultdb`).
3. On the same page, **CA certificate** → *Show* → copy the whole text
   (`-----BEGIN CERTIFICATE----- … -----END CERTIFICATE-----`).

## 2. Photos: Cloudinary

https://console.cloudinary.com → **Settings → API Keys**. Copy **Cloud name**, **API key**, **API secret**.

## 3. Put the code on GitHub

Create an **empty private** repo at https://github.com/new (no README / .gitignore), e.g. `lost-found-backend`, then:

```bash
cd ~/lost-found-backend
git remote add origin https://github.com/<your-username>/lost-found-backend.git
git push -u origin main
```

`.env`, `secrets/` (Firebase key), `uploads/`, `logs/` and `node_modules/` are git-ignored — they never leave your Mac.

## 4. Create the Render service

1. https://dashboard.render.com → **New → Blueprint** → connect GitHub → pick the repo.
   Render reads `render.yaml` and creates **lost-found-api** (free, Singapore).
2. Fill in the values it asks for:

| Key | Value |
|---|---|
| `DB_HOST` / `DB_PORT` / `DB_USER` / `DB_PASSWORD` | from Aiven |
| `DB_NAME` | `defaultdb` |
| `DB_SSL_CA` | the CA certificate text from Aiven (paste as is) |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | your admin-panel login (**strong password** — the default is refused in production) |
| `CLOUDINARY_CLOUD_NAME` / `_API_KEY` / `_API_SECRET` | from Cloudinary |
| `FIREBASE_SERVICE_ACCOUNT_JSON` | optional: paste the full contents of `secrets/firebase-service-account.json` to turn on push |

JWT and session secrets are generated by Render automatically.

3. **Apply**. The first deploy installs packages, creates the tables, adds the categories and
   the admin user, then starts. Check it:
   - `https://lost-found-api.onrender.com/api/v1/health` → `"status": "ok"`
   - `https://lost-found-api.onrender.com/admin` → admin login
   - `https://lost-found-api.onrender.com/api-docs` → Swagger

   (Your URL is shown at the top of the service page; the name may have a suffix.)

Every `git push` to `main` redeploys automatically. New migrations run on start.

## 5. Build the APK pointing at Render

```bash
cd ~/lost_found_app
flutter build apk --release --dart-define=API_URL=https://lost-found-api.onrender.com
```

The APK is at `build/app/outputs/flutter-apk/app-release.apk` — send it to any Android phone and install
(allow "Install unknown apps"). For a smaller download per phone type, use
`flutter build apk --release --split-per-abi --dart-define=API_URL=…` and share `app-arm64-v8a-release.apk`.

> The release build is signed with the debug key — fine for sharing the APK directly.
> For the Play Store you'll need your own upload keystore.

## Good to know (free tier)

- **Cold start:** after 15 idle minutes the first request takes ~50 s. The app waits up to 70 s and
  shows "the server may be waking up" if it still times out.
- **Logs:** Render dashboard → service → *Logs*.
- **Database backups:** the Aiven free plan is for trying things out; export important data regularly.
- **Changing secrets** (e.g. `JWT_ACCESS_SECRET`) logs everyone out.
